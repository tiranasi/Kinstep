# KinStep（亲程）

ENT303 手机网页原型。长辈查看当前就医任务，子女管理就医进度、单据与用药安排。

## 启动

需要 Node.js 24 或更新版本。依赖已经安装；换电脑后先运行 `npm.cmd ci`。

```powershell
cd D:\XJTLU\course\G4\ENT303\software
npm.cmd run dev
```

打开 [http://localhost:3000](http://localhost:3000)。身份入口提供“我是长辈”和“我是子女”。

两端演示请使用两台设备，或两个独立浏览器会话。普通标签页会共享登录身份。两端读取同一个家庭记录，每两秒同步；登录有效期为七天。

正式构建与启动：

```powershell
npm.cmd run build
npm.cmd run start
```

## 模型、语言与局域网

在子女端打开“设置 → AI 模型”，填写请求 URL、模型名和 API Key。地址可使用接口根地址或完整的 `/chat/completions` URL。问答需要支持 JSON 输出的接口，截图和单据识别还需要支持图片输入。保存后用于后续请求，密钥保存在服务端。更换接口地址时，请填写该地址对应的密钥。

也可复制 `.env.example` 为 `.env.local` 后填写以下字段。页面保存的设置优先。

```dotenv
DEEPSEEK_API_KEY=填写你自己的密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-flash
```

登录页及两端设置都可切换简体中文和英文。语言按浏览器记忆，上传单据和用户录入的字段保留原文。

服务启动后，子女端的“设置 → 局域网访问”会列出地址。手机与电脑连接同一网络后打开对应地址。若无法访问，检查 Windows 防火墙是否允许 Node.js 在专用网络接收入站连接。网页麦克风需要可信 HTTPS，局域网 HTTP 页面可使用手机键盘听写。

## 已有功能

- 身份入口、记住会话、切换身份。
- 长辈端的大字当前任务、明确主按钮、就医安排、已完成步骤与语音播报。
- 子女端的概览、单据、用药三个页面，以及进度时间线、原图、字段核对、预约编辑。
- 到院、报到候诊、接诊、检查、带报告再接诊、缴费取药、就医完成；也可确认无需检查或无需取药。
- 检查逐项记录费用处理、检查完成、报告取得；支持两项以上检查，不会完成一项就结束全部检查。
- 拍照或相册选图、预览、上传识别、结果确认、原图归档、重复图片去重、手动补充。提前归档的单据可在相应阶段再次确认使用。
- 处方形成服药草稿，子女对照来源核对用法和提醒时间，取药并结束就医后启用提醒。
- 页面内到时提示、播报、逐次确认服药、稍后提醒、本次未服记录。未回应显示待确认。旧日期的未确认记录保留，不作为今天的服药指令。
- 找家人求助标记、子女处理求助、撤销最近一次操作、演示场景切换。
- 浏览器中文语音识别、可修改的文字输入、助手回答；语音提出完成动作时，确认后才更改记录。

## 界面约定

采用已确认的老人端 V3 与子女端示意图：冷灰背景、白色分组、克制的蓝色、系统字体、轻微毛玻璃底栏，详情使用抽屉渐进展开。长辈首页主标题 36–39px，任务信息约 29–31px，主按钮 26px、至少70px高。“说句话”是底部常用工具，与“拍单据”“找家人”并列。

## 完整演示

初次打开使用空白记录。打开“子女端 → 设置 → 案例模式”可载入预约，并在概览的“就医资料”中查看检查、费用、检验报告与处方。可问助手“下一步去哪”“血常规多少钱”“报告写了哪些数值”。案例资料供查看与问答，就医状态由用户逐步确认。

1. 子女打开“查看就医安排”，可以编辑预约。
2. 长辈依次点击“我到医院了”“我已报到”“轮到我了”。
3. 长辈点击“拍单据”，展开“选择已有单据”，选择检查申请单，确认结果。
4. 确认费用处理和检查完成。上传示例检验报告并确认，或手动确认拿到报告。
5. 点击“去找医生看报告”，确认医生已看过，并选择需要取药。
6. 上传示例处方，确认形成草稿；确认费用处理、取到药，就医完成。
7. 子女进入“用药”，打开药品，核对用法、设置提醒时间与周期，保存并启用。
8. 长辈在到时卡片确认本次服药。子女端会同步记录。

案例模式和日常记录分别保存。关闭案例模式后，子女可在设置填写称呼，并通过“添加就医安排”上传挂号截图、语音录入或手动填写。模型提取的信息先进入表单，核对并保存后才会同步给长辈。

“重置案例”将案例恢复到出发前。“预览服药提醒”仅播放提示。

## 技术与文件

使用 Next.js App Router、React、TypeScript、TanStack Query、Lucide 图标、Zod 校验与普通 CSS。前后端为同一个 Node.js 服务。SQLite 分别保存日常记录、案例记录与设置。并发操作使用版本号校验，冲突时提示重新查看。

| 路径 | 用途 |
|---|---|
| `src/components/` | 两端页面、登录、单据、语音、详情抽屉 |
| `src/app/globals.css` | 适老化与苹果风格的布局、字体、颜色、毛玻璃 |
| `src/lib/domain.ts` | 统一业务规则与状态转换 |
| `src/lib/db.ts` | SQLite、会话与事务 |
| `src/lib/assistant.ts` | DeepSeek 图片提取与问答 |
| `src/app/api/` | 会话、共享状态、单据与问答接口 |
| `data/companion.sqlite` | 运行后生成的持久化数据 |
| `data/uploads/` | 上传图片，只有登录后可以访问 |
| `tests/` | 业务规则测试 |
| `scripts/api-smoke.mjs` | 真实 HTTP 接口的完整流程检查 |
| `output/playwright/` | 实际界面截图 |

运行数据、依赖与密钥均已列入 `.gitignore`。运行环境需要可持久保存数据的本地磁盘，不使用静态网页托管方式。

接口：`GET/POST/DELETE /api/session`、`GET/POST /api/state`、`POST /api/documents`、`GET /api/documents/:id`、`POST /api/chat`。状态变更提交 `{ revision, action }`；后端执行规则，不接受前端直接覆盖整份进度。

## 检查

```powershell
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
```

服务器运行时可做接口检查：

```powershell
$env:TEST_BASE_URL='http://localhost:3000'
npm.cmd run test:api
```

接口检查会切换案例模式、修改模型设置和写入预约。请在空白的测试数据库中运行，可用 `APP_DATA_DIR` 指向独立目录。模型接口用本地服务验证。

## 需要在演示手机上继续确认

浏览器的 `SpeechRecognition / webkitSpeechRecognition` 是否能稳定识别中文，需要在实际手机上验证。页面已提供文字输入，可以使用系统键盘的听写入口。手机通过局域网 HTTP 地址访问时，麦克风可能不可用；麦克风演示需要可信 HTTPS。电脑的 localhost 可以进行开发测试。

提醒使用打开网页后的页面提示与播报。语音播放仍受浏览器的播放权限控制。手机拍照上传、中文听写、声音播放与锁屏行为不属于本次桌面浏览器验证的结果。
